    数字键或鼠标选字，- = 翻页，单按 Shift 切换中英文

    检测到系统输入法正在处理按键。请把系统输入法切换到英文（如 macOS 的 ABC、Windows 的英语键盘），就能用上水杉。

    这个演示需要实体键盘。手机和平板上请连接键盘，或在电脑上打开。

    完全离线

    引擎、词库和整句模型都在浏览器的 Web Worker 里运行。没有服务器参与转换，输入的内容不会被上传。

    和桌面版同一个引擎

    与 macOS、Linux、Android、iOS、HarmonyOS 版共用一套 Rust 输入引擎，同样的词库，同样的候选排序。

    两行代码嵌进你的网页

    以 npm 包 @msime/web-engine 发布，可部署到 GitHub Pages、Vercel、Cloudflare 等任意静态托管，也能直接从 CDN 引用。

    接入你的网站

    HTML
    <textarea></textarea>
<script type="module">
  import { createMsimeEngine, attachInput } from "https://cdn.jsdelivr.net/npm/@msime/web-engine/index.js";
  const engine = await createMsimeEngine({ scheme: "quanpin" });
  attachInput(document.querySelector("textarea"), engine);
</script>

    挂在普通文本框上时，访客开着系统中文输入法的话按键会先被系统输入法接走，需要切换到英文输入才能用上水杉；这个页面的输入区不是可编辑元素，所以不受影响。部署到自己的站点、打包器、各托管平台的配置和 CSP 说明，见 接入文档。
